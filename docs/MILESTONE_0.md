# Milestone 0 — Kovu vertical slice

## Success criteria

1. Project compiles against Minecraft 1.21.1 + NeoForge + Circle of Craft.
2. Game starts with Circle of Craft, GeckoLib, and Pride's Legacy loaded.
3. `/summon prideslegacy:kovu` spawns a visible lion entity.
4. Prototype Kovu uses Circle of Craft's lion mesh and Scar texture by resource reference.
5. Kovu is always male and does not despawn while we inspect him.
6. No natural spawn rules are added yet.

Once this passes, Milestone 1 replaces the placeholder appearance and adds Kovu-specific NPC behavior/dialogue.
